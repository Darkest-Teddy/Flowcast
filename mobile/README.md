# mobile (React + TypeScript + Tailwind CSS)

Owner: Mobile Web / Product & Pitch Lead (see `.plans/campus-digital-twin-spec.md` Section 2).

The phone-facing page people reach by scanning the QR code. No install, no account wall (Section 9).

## What goes here
- Persona builder: name, schedule entry, home building, habits, avatar color/accessory (Section 7.2)
- Follow-your-agent view: live status line for the user's own agent
- Voting UI: single-tap ballot with live results
- The data-retention consent notice (Section 10.1) — required text, not optional, since the team decided to keep persona data after the event
- Accessibility requirements from Section 10.3: contrast, non-color-only avatar distinction, large tap targets, ARIA labels
